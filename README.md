# Forecast Guidance Archive & Verification Notebooks
### 🚀 Google Colab Notebooks for Operational Forecasting

## 📌 Overview
This repository contains a series of Google Colab notebooks designed to help operational forecasters quickly and efficiently re-create forecast guidance images from archived datasets stored on AWS, Azure, and Google Cloud platforms. These notebooks also enable event-based verification of forecast guidance at various point locations across the state.

## ⚡ Features
✔️ Retrieve Archived Forecast Images – Access past forecast data stored on major cloud platforms (AWS, Azure, Google Cloud)
✔️ Event-Based Verification – Compare forecast guidance with observed data at key locations
✔️ Quick & Easy Visualization – Generate publication-ready forecast maps for post-event analysis
✔️ Google Colab Integration – No setup required—run the notebooks in Colab with cloud-based compute power

## 📂 Contents
📘 Forecast Archive Retrieval – Load and visualize past model runs from cloud archives
📘 Event-Based Verification – Compare model forecasts with actual observations at specific locations
📘 Customizable Visualization – Modify parameters for location, time range, and forecast variables
## 🔧 Requirements
Google Colab (recommended) or Jupyter Notebook
Python libraries: xarray, matplotlib, numpy, pandas, boto3, azure-storage-blob, google-cloud-storage, herbie
API access to AWS, Azure, or Google Cloud storage for forecast data retrieval
## 🚀 Getting Started
Open a Notebook in Google Colab
Click on a notebook file (.ipynb) in this repo and select "Open in Colab"
Run the Code
Follow the provided steps to authenticate cloud storage access and retrieve forecast guidance
Analyze & Visualize
Adjust parameters to generate maps, compare datasets, and verify event-specific forecasts
